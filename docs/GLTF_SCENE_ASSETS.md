# glTF scene assets and the world-renderer adapter

Status: implemented for the bounded subset below and exercised by the
[scene fixture](SCENE_FIXTURE.md). This is not general glTF support.

## Why it exists

`Model` uploads OpenGL resources in its constructor, so CPU-only consumers
(tools, importers, headless checks) cannot use it. The scene path publishes a
fully owned CPU snapshot of one glTF document and submits it through the
existing shared world renderer, without constructing a `Model`, adding a
renderer abstraction, or introducing a new cooked format.

## Public interface

`engine::render::gltf::scene` in
[`GltfSceneAsset.h`](../src/engine/render/gltf/GltfSceneAsset.h) and
[`GltfSceneRenderer.h`](../src/engine/render/gltf/GltfSceneRenderer.h):

- `loadGltfSceneAsset(path, out, error, options)` is synchronous and CPU-only.
  It builds and validates a private snapshot, then publishes it. On failure the
  caller's `out` and its previous shared payload are unchanged and `error`
  carries the diagnostic. The published asset owns decoded geometry, indices,
  node/skin/clip arrays, materials and pixels; no live `fastgltf` view or file
  dependency remains. `sourceIdentity` hashes the main document bytes;
  `generation` distinguishes snapshots and their poses. Geometry and texture
  keys also hash their owned payloads, including external-buffer/image changes.
  Identical content may reuse GPU cache entries. A failed reload leaves the old
  asset and its identities intact.
- `sampleGltfScenePose(asset, timeSec, clipIndex, outPose, error)` reuses the
  shared `animation::samplePose` policy. `kBindPoseClip` (`-1`) is the explicit
  bind pose. Each skinned mesh node's palette entry is
  `inverse(meshGlobal) * jointGlobal * inverseBind`; the adapter submits the
  mesh node's global transform as the model matrix, so the rendered result is
  `jointGlobal * inverseBind` and the non-identity mesh transform cancels
  exactly. Static mesh nodes keep their node transform. A pose records the asset
  identity and generation; a failed sample leaves the caller's previous pose
  unchanged, and a pose from another generation is rejected by the adapter.
- `drawGltfSceneAsset(renderer, asset, pose, options, stats, error)` submits the
  asset's owned vertices, indices, five decoded map roles and scalar factors
  through `drawWorldIndexedMeshTexturedCached`. Borrowed pointers are valid for
  the call; the caller owns the asset and pose until it returns. The adapter
  retains no renderer pointer and must be used from the owner thread.

`Stats` record node/primitive/vertex/index/material/skin/clip counts, retained
geometry and decoded texture bytes and the wall-clock load time; the pose records
its own sample time. `retainedAssetBytes` sums vertex/index and decoded pixel
payloads; it excludes node/skin/clip arrays, container overhead and allocator
capacity. Timings are measurements for these inputs, not a performance budget
or a GPU-residency claim.

## Supported subset

- One scene: only meshes reachable from the default scene, or the first scene
  when no default is declared. Node indices remain stable for skin/clip bindings.
- Indexed or generated-index `TRIANGLES` primitives.
  Source CCW indices are converted to the world pipeline's CW convention after
  normal/tangent generation, keeping exterior lighting correct.
- Multiple mesh nodes, primitives, materials and skin joints per asset.
- `POSITION`, `NORMAL`, `TANGENT`, `TEXCOORD_0`, `COLOR_0`, `JOINTS_0`,
  `WEIGHTS_0`; missing normals/tangents are generated by the existing helpers.
- Four weights per vertex and at most 64 joints per skin.
- `LINEAR`, `STEP` and `CUBICSPLINE` translation/rotation/scale samplers through
  the shared sampler.
- OPAQUE, MASK and BLEND materials, shared UV0, no texture-transform extension;
  repeat, clamp-to-edge and mirrored-repeat wrapping; omitted or LINEAR `minFilter` and
  omitted or LINEAR `magFilter`. Opaque base alpha and vertex alpha remain 1.
  MASK/BLEND retain their base alpha and cutoff through the native material path.
  Opaque/masked surfaces draw before transparent overlays, with authored order
  preserved within each pass (no triangle-level transparency sorting).
  Omitted minification uses renderer mip/anisotropy policy. Explicit LINEAR
  uploads only the authored base level, with bilinear filtering on all APIs.
  Other explicit minification filters and nearest magnification are rejected.
  Missing material bindings use
  an owned glTF default material.
- `baseColorFactor`, `emissiveFactor`, `metallicFactor`, `roughnessFactor`,
  normal `scale` and occlusion `strength`; RGB base factors through
  `WorldTextureData.vertexColorMul`, emissive factors as separate fields.
  Factors are finite and range-checked; this subset admits normal scale 0–100.
  `GltfSceneDrawOptions.baseColorFactors` can supply one linear RGBA factor per
  material for animated inputs; invalid counts/values fail before submission.
- `KHR_materials_unlit`, including required usage, uses the shared unlit world
  material path while preserving base color, texture, wrapping and alpha mode.
- PNG/JPEG images through the existing decode routes (including their documented
  role fallbacks for a present but undecodable payload).

Missing UVs are accepted only when no authored map needs them. A genuinely
absent emissive map binds implicit white so the separate `emissiveFactor`
contributes; a present but corrupt emissive map keeps the existing decoder
fallback. Double-sided materials, extra UV sets, texture
transforms, morph targets, extra joint sets, non-`TRIANGLES` topology,
unsupported attributes and unsupported material extensions are rejected with a
diagnostic that names the offending feature.

## Load options

`GltfSceneLoadOptions` bounds nodes, primitives, vertices, indices and retained
decoded texture bytes, with checked arithmetic. These limits bound admitted
output; they are not a hard peak-memory or untrusted-input sandbox guarantee.
Parser and decoder temporaries and filesystem reads are outside the accounting.
Assets that exceed a limit are rejected without publishing anything.
References, loaded buffer/view/accessor ranges, hierarchy, skin data and
animation channel shape/counts are checked before the shared decoding helpers.
Sparse accessors are explicitly unsupported. Required extensions other than
`KHR_materials_unlit` are rejected;
the legacy parser's extension recognition does not imply scene-path support.

## Limits and follow-up

Direct import is synchronous. The store overload and
[archive-backed scene session](GLTF_SCENE_SESSIONS.md) provide background glTF
decoding and atomic activation. Pass an explicit
[resource scope](WORLD_RESOURCE_SCOPES.md) through draw options to own and release
the scene's native cached resources. CPU snapshot release alone still does not
evict GPU resources; scope zero keeps legacy unowned cache behavior. The path
does not claim general glTF or full PBR conformance.
Texture decoding goes through the shared decoders, so a consumer that sets the
existing `PHLOSION_GLTF_DEBUG_*`/`PHLOSION_GLTF_DUMP_TEXTURES` flags still gets
that diagnostic behavior; the scene sample scopes those flags off around its own
loads so its captures stay hermetic.
