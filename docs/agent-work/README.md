# Engine development records

Record lasting design decisions, qualification summaries, and reproducible
commands here. Keep raw logs, captures, handoff receipts, and one-off job
scripts in the ignored local task artifacts. Reusable verification tools live
in the engine's `tools/` directory.

The [lighting and reflection records](lighting-foundation/COMPLETE_TECHNIQUE.md)
cover renderer integration, tests, and performance measurements. Historical
examples use placeholders for workstation names, device identifiers, and
local evidence directories. Substitute paths and identifiers for your own
environment when adapting those examples.
