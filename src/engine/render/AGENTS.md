# Rendering work

Prioritize visible rendering artifacts and movement hitches. Use measured
departures from reference behavior where they improve the result. Preserve the
connected renderer and verify appearance, frame-time tails and normal hosts.

For lighting/reflection architecture or performance work, read and follow
[the complete-technique contract](../../../docs/agent-work/lighting-foundation/COMPLETE_TECHNIQUE.md)
and its source trace before editing. The target is the connected ordinary raster
pipeline described there. The supported ordinary Windows path is qualified in
[contact-shading acceptance](../../../docs/agent-work/lighting-foundation/CONTACT_COMPLETION.md),
[offscreen-probe acceptance](../../../docs/agent-work/lighting-foundation/OFFSCREEN_REFLECTION_COMPLETION.md),
and [screen-reflection acceptance](../../../docs/agent-work/lighting-foundation/SCREEN_REFLECTION_COMPLETION.md).
Broader material systems, platforms and separate rendering categories retain
their own acceptance gates.

Implement producer/history/reconstruction/consumer dependencies together.
Further sample caps or visual shortcuts do not replace missing stages. Keep
intermediate milestones explicitly incomplete and use the contract's source-to-
implementation-to-test evidence when reporting completion.
